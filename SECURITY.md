# Security policy

This pre-release project has no formal support SLA. Please report suspected vulnerabilities privately using the repository owner's GitHub private vulnerability reporting facility if it is enabled. If it is unavailable, ask the owner for a private reporting channel without posting exploit details or secrets publicly.

Include a minimal reproduction, affected commit, environment, impact and suggested mitigation. Do not attach Twitch tokens, operator keys, raw camera frames or private logs. Do not test against third-party systems or live viewers without authorization.

See docs/SECURITY.md for implemented boundaries and known limits. Simulated threat events are game mechanics; they never authorize real attacks. Local tests and dependency checks are not an independent security audit.
