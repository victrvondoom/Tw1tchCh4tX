# Test harness

Install Node 24.x (24.15+), run `npm ci`, then `npx playwright install --with-deps chromium`. No credentials, webcam or external Twitch session is needed for the deterministic suite.

| Command                 | Purpose                                                           |
| ----------------------- | ----------------------------------------------------------------- |
| `npm run secrets:check` | Scan source and tracked filenames for common secret patterns      |
| `npm run format:check`  | Prettier consistency                                              |
| `npm run lint`          | ESLint, zero warnings                                             |
| `npm run typecheck`     | Strict TypeScript across runtime and tests                        |
| `npm test`              | Unit, integration, component and contract tests                   |
| `npm run test:coverage` | V8 coverage with 80% line/statement/function and 70% branch gates |
| `npm run build`         | Vite client and Node ESM server bundle                            |
| `npm run test:e2e`      | Four browser acceptance journeys against production build         |
| `npm run harness`       | All required checks in sequence                                   |
| `npm audit`             | Current dependency advisory check                                 |

Physics tests exercise all authored solutions and 1,000 seeded reflection invariants. Game tests cover interrupted charging, time/health loss, vote ties, exhausted defenses, move budgets, participation, reset/next and persistence exactly once. Security tests cover parser boundaries, cooldown, replay, cache/queue caps, stale commands, OAuth state and session expiry.

HTTP integration tests use Fastify injection; WebSocket authorization uses actual local sockets. Persistence tests reopen a real temporary database and verify retention and schema guards. Twitch tests use injected fetch/socket/clock fixtures for consent scopes, identity validation, refresh, subscription errors, migration, retries, keepalive expiry, revocation, hostile URLs and cancelled exchange. These are protocol mocks, not live Twitch certification.

Browser journeys cover a complete win and history, next/pause/resume, read-only transparent overlay, all mission selection, invalid command rejection, camera denial and mouse fallback, mobile overflow/dialog dismissal, spectator lock and disconnected state. Screenshots are generated by these tests into `docs/screenshots`; they are genuine app captures. The HTML report and retained failure traces are untracked artifacts.

In a constrained executor, `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` can select an installed Chromium and `PLAYWRIGHT_SINGLE_PROCESS=1` gives each test a fresh single-process browser. These flags are optional diagnostics, not the CI default. The recorded local run used official Chrome Headless Shell 131.0.6778.204; CI installs Playwright's matching browser. The initial [GitHub Actions run](https://github.com/victrvondoom/Tw1tchCh4tX/actions/runs/40467561275) also passed on implementation commit `bb38afc`, including a clean npm install, Playwright-managed Chromium, the complete harness and dependency audit.

Coverage intentionally targets physics/contracts and server game/security/storage/Twitch logic. Coverage output is the authority on which files were instrumented; UI, HTTP integration behavior and gaze lifecycle need the separate test evidence. Real-camera calibration accuracy, actual Twitch accounts, native OBS, Docker runtime and cross-browser compatibility remain manual checks.
